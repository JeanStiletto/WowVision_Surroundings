# WowVision Surroundings data

Map data for the surroundings of [WowVision](https://github.com/wow-vision/WowVision) on
WoW: Forever, TBC Anniversary and Classic Era. With it, WowVision describes where you walk: the land, roads and streets, city
squares, rooms of buildings, drop edges, entrances and what you bump into. What is said and how
to use it: WowVision's documentation, "Surroundings (WoW: Forever)".

Covered so far:

- TBC Anniversary: Elwynn Forest with Stormwind, Dun Morogh with Ironforge, Tirisfal Glades with Undercity, the
  Deeprun Tram, Teldrassil with Darnassus, and the Swamp of Sorrows.
- WoW: Forever: Elwynn Forest with Stormwind, Dun Morogh with Ironforge, Tirisfal Glades with Undercity, the Deeprun
  Tram, and Zephras Isle.
- Classic Era: Elwynn Forest with Stormwind, and Dun Morogh with Ironforge.

Place and building names are in English, German and French.

WowVision's bump module (what the player bumps into: `core/navigation/bumps.lua`) takes its own small data from
these zone files: its `tools/bumps/pack.lua` keeps the objects, the buildings' rooms and doorways and the
structures, and writes them into WowVision's `mapdata/bumps/` (see its `tools/bumps/README.md`).

## How WowVision uses it

This repository is not an addon of its own. It is a git submodule of WowVision at
`mapdata/WowVision_Surroundings`, the way WowVision's `locale` folder is. WowVision packs each client's folder for
the game (its `tools/surroundings-pack.py`, into `mapdata/WowVision_SurroundingsPacked/<client>/`), and
`camelot/modules.xml`, `tbc/modules.xml` and `vanilla/modules.xml` include the packed `forever`, `tbc` and `era`
folders, so the data loads as part of WowVision. Nothing extra is installed. An older separate addon folder
`WowVision_Surroundings` in the game's addons folder is no longer used and should be removed.

## Layout

- One folder per game version, each with the same layout (`data.xml`, `zones/`, `places/`):
  `forever/` (WoW: Forever; at the repository's root until 2026-10-24), `tbc/` (TBC Anniversary),
  `era/` (Classic Era), each exported from its own client (WowVision's `tbc/modules.xml` and `vanilla/modules.xml`
  include their `data.xml`). WoW: Forever rebuilt the world (its cities are new files, terrain and
  objects differ in every zone), so its data does not fit the classic clients; Era and TBC
  Anniversary are close but not the same (Elwynn: the Westbrook barracks, the Forest's Edge tower,
  the Valley of Heroes), so each has its own files.
- `zones/`: one generated file per zone. It registers the zone's frame and its data as JSON text;
  WowVision decodes and unpacks a zone only while the player is in it. The format (format 4) is
  described in WowVision's developer documentation, "Surroundings (WoW: Forever)".
- `places/`: one generated places list file per zone (WowVision's places list, Alt-F10).

The files are generated by the wv-surroundings tools (`tools/export.py`, written by
`tools/store.py`). Edit them through the generator, not by hand. They are plain text, one row or
record to a line, so git shows what an export changed.

## Sources

The data is generated offline from the WoW: Forever client's own map files (terrain, buildings
and their rooms and doorways, water, objects), its database tables (AreaTable, WMOAreaTable,
with Classic Era's for the originals of rebuilt places) and the community listfile for model
names. Shop sign names and their German and French forms come from the cMaNGOS classic-db and
AzerothCore databases.
